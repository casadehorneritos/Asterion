# Asterion

Plataforma de escritura y lectura enfocada en la curaduría de contenido de calidad, diseñada para dar visibilidad a autores originales y evitar la saturación de contenido de baja calidad.

## 🚀 Estado del Proyecto
Beta en desarrollo.

## 🛠️ Stack Tecnológico (Planificado)
- **Frontend:** React Native (Web + Móvil)
- **Backend:** Node.js
- **Base de Datos:** PostgreSQL
- **Arquitectura:** Monolito Modular

## 📂 Estructura del Repositorio
- `/frontend`: Interfaz de usuario.
- `/backend`: Lógica del servidor y base de datos.
- `/docs`: Documentación, reglas de negocio y diseño.
